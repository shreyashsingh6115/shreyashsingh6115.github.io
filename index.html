SafeWay-AI — Road Safety Intelligence System

Machine learning · multi-model pipeline

Indian roads see over a lakh fatalities a year, and a large share trace back to three preventable things: drowsy drivers, lane drift, and slow response after a crash. SafeWay-AI watches for all three from a single video feed.

  • Accident detection — YOLOv8 object detection tuned to flag collision events in traffic footage.
  • Lane monitoring — OpenCV-based lane extraction, flagging unintended departures.
  • Drowsiness detection — CNN+LSTM over facial frames, so the model reads eye closure over time instead of judging a single frame.
  • Classification ensemble — EfficientNetB0 and ResNet50 combined, reaching 97.71% accuracy.

Plant Disease Detection using Deep Learning

Machine learning · image classification

A farmer noticing a sick plant late loses the crop. This classifier takes a phone photo of a leaf and names the disease, so diagnosis happens in the field instead of a lab queue.

  • CNN architecture trained on labelled leaf imagery across multiple disease classes.
  • Preprocessing and augmentation pipeline — resizing, normalisation and transforms — to stop the model memorising lighting instead of learning disease.
  • Evaluated on held-out data to check it generalises past the training set.
